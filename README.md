# Sonsuz Merhaba Dünyası Üreticisi

## Giriş (Ciddi Bölüm)

Bu proje, insanlığın en temel ihtiyacı olan "selam vermek" eylemini, mümkün olan en yavaş, en dramatik ve en anlamsız şekilde gerçekleştirmek için tasarlanmıştır. Geleneksel "Hello World" programları çok hızlı ve özensizdir. Biz ise her harfin evren tarafından onaylanmasını bekleriz.

**Amaç:** Dünyayı kurtarmak değil, dünyaya yavaşça merhaba demek.

## Özellikler

- Sonsuz döngüde çalışır (piliniz bitene kadar).
- Her karakter 0.8 saniye bekler. Sabır testi.
- Ctrl+C ile durdurulabilir ama içinizde sonsuz bir "Merhaba" kalır.
- Tamamen Türkçe. İngilizceye ihanet etmez.
- Hiçbir şey yapmaz ama yapar gibi görünür. Mükemmel.

## Kurulum ve Kullanım

1. Bu repoyu klonlayın (neden klonladınız bilmiyorum ama):
   ```
   git clone https://github.com/Tentivory/sonsuz-merhaba-dunyasi-ureticisi.git
   ```
2. Çalıştırın:
   ```
   python merhaba.py
   ```
3. İzleyin. Düşünün. Pİşman olun. Tekrar izleyin.
